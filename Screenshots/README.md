# Windows-Server-Enterprise-Lab
Enterprise Windows Server 2022 Home Lab with Active Directory, DNS, DHCP, Group Policy and File Services

## Overview

This project demonstrates the deployment of a small enterprise Windows infrastructure using Microsoft technologies.

The environment was built from scratch to simulate a real business network and to gain hands-on experience with Windows Server administration.
